Motor Hisab Book
================

Files:
- index.html: the app
- manifest.json: installable app metadata
- sw.js: offline cache

How to use:
1. Upload all three files to the same folder on GitHub Pages or Netlify.
2. Open the HTTPS website in Chrome on Android.
3. Use Chrome menu > Install app / Add to Home screen.
4. Start with Pintu Patel or Jay Patel. No transactions are preloaded.
5. Add entries by choosing a date on the calendar.
6. Use Settings > Backup regularly. Backup is important before clearing browser data or changing phones.

Data:
- Entries are stored locally in the browser on this device.
- The app starts with zero transactions. Motor type names are only starter options and can be edited by adding new types.
- This first version does not sync automatically between phones.
